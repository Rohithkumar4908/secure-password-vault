Face and voice unlock

Enrol once while unlocked. Next time you can unlock with your face (and your voice passphrase, if set) instead of typing. The master password always still works. Face is stored as 128 numbers and voice as a sound pattern, both only in this browser. No photo or recording is saved.

Limits: this is a convenience gate, not strong security. A photo or a recording could fool it, because there is no liveness check. Voice is a passphrase pattern match, not true speaker identification.

Two-step verification (parent device)

After the password (or face/voice) step, the vault asks for a 6-digit code from an authenticator app on the parent's phone (Google Authenticator, Microsoft Authenticator, Aegis). Codes are made on the phone and checked here, so it needs no server, no SMS and no internet.

On the parent's phone: open the authenticator app, scan this QR code (or enter the key by hand), then type the code it shows.

Parent alerts (free push, needs internet)

Optional. The parent installs the free ntfy app and subscribes to a secret topic name. The vault then sends a push when someone unlocks it or fails to. This is an alert only, not an approval: a server-less page cannot wait for a tap from the parent. Anyone who knows the topic name can read the alerts, so make it long and random.

Encrypted backup

Downloads one encrypted file (still protected by your master password). Move it to another laptop and import it there.

Restore from backup

Replaces the current vault contents with the backup (you will be asked for the master password and phone number the backup was made with; it works on any laptop).
